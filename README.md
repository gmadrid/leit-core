# leit-core

Shared Rust crates underpinning Leitner-box / spaced-repetition study apps.

Used by:
- [bjsc](https://github.com/gmadrid/bjsc) — blackjack strategy chart trainer
- [leitspeed](https://github.com/gmadrid/leitspeed) — playing-card stack memorization

## Crates

- `spaced-rep` — generic Leitner-box spaced-repetition engine.
